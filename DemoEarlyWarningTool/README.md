# Student Early Warning Predictive Model (KNIME)

This repository contains the workflow and dataset for predicting student performance risks using machine learning algorithms built in KNIME Analytics Platform.

## Included Repository Files
- `DemoEarlyWarningTool.knwf` — Exported KNIME workflow pipeline
- `student_performance_knime.csv` — Primary dataset used for model training and evaluation

## Implemented Models
- Decision Tree Classifier
- Logistic Regression
- Random Forest Classifier

## Execution Steps
1. Launch KNIME Analytics Platform and import `DemoEarlyWarningTool.knwf`.
2. Locate the CSV Reader node and update the path to target `student_performance_knime.csv`.
3. Run all workflow nodes to process the dataset and train models.
4. Open the interactive views or Scorer nodes to evaluate model predictions.
